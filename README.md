專案簡介
這是一個輕量化 Web 系統，旨在解決消費者在結帳前「忘記哪張卡回饋最高」的困擾。
使用者只需輸入店家名稱或選擇類別，系統將自動比對資料庫並依回饋率高低排序推薦卡片以及該切換甚麼方案
如果你是:
1.多卡族： 擁有多張信用卡，且希望極大化點數或現金回饋的消費者；
2.小資族： 習慣針對特定通路（如外送、超商）選用特定優惠的族群；
3.數位支付新手： 搞不清楚複雜權益（如 CUBE 卡方案切換）的使用者；那這個網頁可能會對你來說很有用!

功能項目
•	智慧關鍵字搜尋： 無論使用者是正確輸入「chatgpt」還是只想輸入「gpt」或是打錯字打成「chitgtp」，都能搜尋到；又或是輸入「多鄰國」也能搜尋到「doulingo」的結果。
•	動態排序系統： 依據回饋百分比（如 5% > 3%）由高至低自動排列。
•	權益切換提示： 特別標註信用卡的方案，讓使用者清楚應該切換甚麼方案。
•	信用卡資訊：網頁輸出的每張信用卡推薦卡片旁，附上官方權益或詳細資訊的超連結，方便使用者一鍵跳轉、查看詳細申辦或使用限制。

使用者體驗設計
1.	首頁即搜尋： 減少冗餘文字，進入網站後視覺焦點即在搜尋框。
2.	三秒原則： 使用者必須在 3 秒內完成「開啟網頁、搜尋、看到結果」的動作。
